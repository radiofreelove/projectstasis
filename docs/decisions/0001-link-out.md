# 0001. Link to official forms and pages instead of copying them

- Status: Accepted
- Date: 2026-11-02

## Context

A guide can either bundle copies of official forms (and then must re-check every copy whenever the state revises one) or link to the state's own copies. Bundling keeps forms exact but turns every revision into maintenance, and a stale copy can mislead. The OHP application process changes often in 2026 to 2028, and the state already publishes the forms in 17 languages.

## Decision

Link to the state's own forms, pages, and phone lines. Do not copy or re-host any official document. State only the facts applicants need to understand the rules, each logged with its source.

## Consequences

- Forms are always the state's current version, with no maintenance here.
- If the state moves a page, the link breaks. The weekly link check finds that and opens an issue.
- Facts the site states in its own words still need review; the claims ledger and dated checkpoints handle that.
